== LDPC復号アルゴリズム：SPA から OMS へ

本章では、高精度な *Sum-Product Algorithm (SPA)* から、ASIC実装に最適な *Offset Min-Sum (OMS) アルゴリズム* への進化と、その演算プロセスの詳細を解説します。

=== 1. 復号の準備と初期化

反復復号を開始する前に、各変数ノードのメッセージを通信路からの受信値で初期化します。
第 0 反復（初期値）として、各 VN stem:[n] から接続される全 CN stem:[m \in \mathcal{M}(n)] に対して、以下の値を設定します。

[stem]
++++
L(q_{n \to m}) = L(q_n)
++++

=== 2. チェックノード (CN) 更新：OMS アルゴリズム

チェックノード stem:[m] では、接続されている全 VN（ただし、送り先の VN stem:[n] を除く）からのメッセージを集計し、新たな信頼度情報 stem:[L(r_{m \to n})] を計算します。

==== 演算式
[stem]
++++
L(r_{m \to n}) = \left( \prod_{n' \in \mathcal{N}(m) \setminus \{n\}} \text{sgn}(L(q_{n' \to m})) \right) \times \max \left( \min_{n' \in \mathcal{N}(m) \setminus \{n\}} |L(q_{n' \to m})| - \beta, 0 \right)
++++

* *符号部*: XORツリーにより、自分を除くメッセージの符号の積（偶奇）を求めます。
* *絶対値部*: 比較器ツリーにより最小値を求め、オフセット因子 stem:[\beta] を減算した後、0 でクリップします。

=== 3. 変数ノード (VN) 更新

変数ノード stem:[n] では、受信値 stem:[L(q_n)] と、周囲の全 CN からの情報を集計し、次回の反復で CN へ送るメッセージおよび事後尤度を計算します。

==== VN to CN メッセージの更新
[stem]
++++
L(q_{n \to m}) = L(q_n) + \sum_{m' \in \mathcal{M}(n) \setminus \{m\}} L(r_{m' \to n})
++++
※特定の CN stem:[m] へ送る情報は、**その CN 自身から受け取った情報を除いた**合計値となります。

==== 事後 LLR (判定用) の計算
[stem]
++++
L(Q_n) = L(q_n) + \sum_{m \in \mathcal{M}(n)} L(r_{m \to n})
++++
全ての CN からの情報を加算した結果を用い、判定ビット stem:[\hat{x}_n] を決定します（ stem:[L(Q_n) > 0] ならば *0* 、さもなくば *1* ）。

=== 4. 収束判定と早期終了

毎回の反復後、得られた暫定の推定語 stem:[\hat{\mathbf{x}}] がパリティ検査行列 stem:[H] の条件（ stem:[H\hat{\mathbf{x}} = \mathbf{0}] ）を全て満たした場合、復号成功とみなし、最大反復回数に達する前であっても処理を終了します。これは ASIC 実装において、平均消費電力の低減とスループットの向上に大きく寄与します。
